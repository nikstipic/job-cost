MANAGEMENT / MAKER — V1 PROTOTYPE

1. Double-click index.html.
2. It opens in Chrome/Edge and works locally.
3. Data is saved in that browser using local storage.
4. This is an offline prototype — do not treat it as a backed-up production database yet.

Included:
- Job dashboard
- Jobs
- Cost control
- Materials/site requests
- Trade packages
- Labour
- Bookings/programme
- Site issues
- Maker daily reports
- Management/Maker role selector
